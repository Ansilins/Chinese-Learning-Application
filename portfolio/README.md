# Ansilin Kumar S M — personal website

A single-file static site (`index.html`) built from my CV. No build step.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

The simplest setup is a repository named `Ansilins.github.io`:

1. Create the repository on GitHub.
2. Copy `index.html` to its root and push.
3. The site goes live at `https://ansilins.github.io`.

To edit content, change the text directly in `index.html`. Each section
(`#experience`, `#publications`, `#projects`, …) is a plain HTML block.
